# 書類印刷（汎用版）

狩猟者登録申請書・会費の領収書・修了証などの書類（PDF・画像）に、名簿（Excel）の氏名や住所を差し込んで、まとめて印刷できる無料のアプリです。
インストール不要。名簿や書類はパソコンの中だけで扱い、インターネットへ送ることはありません。

- **紹介ページ**：https://ranona001.github.io/shorui-insatsu/
- **ダウンロード**：[最新版の zip](https://github.com/ranona001/shorui-insatsu/releases/latest/download/shorui-insatsu.zip)（[リリース一覧](https://github.com/ranona001/shorui-insatsu/releases)）
- **使い方**：[使い方.html](https://ranona001.github.io/shorui-insatsu/使い方.html)

## できること

- 狩猟者登録申請書を、免許ごと（第1種銃・第2種銃・わな・網）に自動で振り分けて印刷
- 保険の申込書・報告書など、ほかの書類も名簿から 1 人 1 枚で印刷
- 猟友会以外の書類にも：町内会費の領収書・行事の案内状・講習会の修了証など（見本つき）
- 「名前・種類を自分で設定」で、手持ちの名簿の見出しのまま使える
- 役所でもらった用紙への「文字だけ印刷」にも対応（位置の微調整つき）
- 手元の書類の PDF やスキャン画像から、自分で様式を作れる

## 使い始め方

1. 上の「ダウンロード」から zip を保存し、展開（すべて展開）します。
2. `書類印刷.html` をダブルクリックし、Microsoft Edge か Google Chrome で開きます。
3. 「様式を開く」で `見本` フォルダの `狩猟者登録申請書_見本_様式.json` を選び、名簿は `会員名簿_ひな形.xlsx` を選ぶと、架空のデータで試せます。

くわしくは同じフォルダの `使い方.html` をご覧ください。
アプリは `書類印刷.html` のファイル1つだけで動きます（PDF や Excel を読む部品 pdf.js・SheetJS も、このファイルの中に入っています。ライセンスはアプリの「このアプリについて」で読めます）。

## 入っているもの

| ファイル | 中身 |
|---|---|
| `書類印刷.html` | アプリ本体 |
| `書類印刷_シンプル版.html` | 見た目を飾らない版（機能は同じ） |
| `使い方.html` | 使い方の説明 |
| `会員名簿_ひな形.xlsx` | 会員名簿のひな形（Microsoft 365 / Excel 2021 以降用。架空の記入例入り） |
| `会員名簿_ひな形_Excel2019以前用.xlsx` | 古い Excel 用の同じひな形 |
| `見本/` | 練習用の架空の申請書（PDF）と様式、猟友会以外の書類の見本（領収書・案内・修了証）と架空の町内会名簿 |

## 個人情報について

- 名簿や書類の内容は、使っているパソコンの中だけで扱います。インターネットへ送ることはありません。
- 保存した様式ファイルには、背景・欄・手入力の文字・名簿のファイル名が入ります。名簿の中身は入りません。

## ご注意

- 個人が作った非公式のアプリです。行政や狩猟団体の公式のものではありません。
- 申請書の様式は都道府県や年度で変わります。印刷した書類は、提出前に必ず内容を確かめてください。
- このアプリを使ったことで生じた損害について、作成者は責任を負いかねます。
